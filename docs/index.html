  1. 0.9.0

    LatestOct 10, 2026Hyprland 0.56.2v0.9.0-v0.56.2

    Continuous Stage toggles, scrolling translation, and rendering and drag improvements

    Stage sidebar

    • Optionally keep the active workspace visible, reserve empty workspace slots, show card backdrops, and distribute cards evenly (#45). Active-card glow is opt-in and disabled by default.
    • Click a window preview to activate its workspace and focus that window. Floating windows dragged within their own Stage card now retain the dropped position.
    • Toggle Stage at runtime with hl.plugin.hymission.stage_toggle() / hymission:stage_toggle. A horizontal plugin gesture reveals or hides the sidebar with continuous desktop reservation, reversal, cancellation, and animated settling. stage_enabled now sets startup visibility; config reload preserves the runtime choice. Scrolling layouts translate as a whole without changing column widths or window sizes.
    • Preserve native rounding, decorations, layering, and return animations when dragging between the desktop and Stage cards. Keep drops in card gaps consistent and prevent silent drops from stealing focus.

    Rendering

    • Clip scrolling windows and unpinned floating windows at Stage boundaries with progressive blur and fading. Configure desktop and preview bands independently with stage_scrolling_desktop_edge_width and stage_scrolling_preview_edge_width.
    • Keep pinned floating windows above Stage with native pointer input, and respect window stacking and fullscreen occlusion in previews.
    • Preserve live backdrop blur, shadow cutouts, rounded corners, and edge gradients through overview transitions. Correct clipping of closing windows and shadow rendering beyond Stage content.
    • Apply blur and fading to every overflowing preview edge, including floating previews, while retaining hard clipping when edge widths are zero.

    Gestures and overview

    • Synchronize sidebar movement and returning cards with workspace swipe progress, including fullscreen transitions, pauses, reversal, and cancellation.
    • Return overview windows directly to their Stage cards and retain the intended workspace across compact gesture handoffs. Preserve geometry and clipping when releasing or interrupting a gesture.
    • Fix duplicate sidebar movement and workspace-strip wallpaper rendering. Ignore empty overview opens, limit workspace creation during a single swipe, and correct hover-only preview expansion.
    • Route layout-scroll gestures to the hovered Stage workspace, preserve its canvas offset when activating it, and scroll explicitly selected windows into view.
    • Fix the Lua stage_toggle action alias so Win+four-finger horizontal gestures register as continuous Stage gestures.

    Capture integration

    • Expose rendered Stage window geometry, clipping, stacking, and rounded corners to HyprCapture. Separate screenshot input suppression from rendering so selection does not also activate a workspace.
    • Avoid render-hook conflicts with Viewflow and transform its shadows with overview previews.

    Validation

    • CMake Release and Meson Release builds and regression suites validated against Hyprland 0.56.2. Live compositor behavior requires a user-run plugin update and session validation.

  2. 0.8.0

    Sep 12, 2026Hyprland 0.56.2v0.8.0-v0.56.2

    Stage workspace sidebar and overview navigation

    Stage workspace sidebar

    • Add an optional persistent workspace sidebar with live window previews, native gap integration, background blur, and animated workspace transitions. Stage mode is disabled by default.
    • Add Smartisan mode, alternating the sidebar side on workspace switches.
    • Support trackpad workspace transitions and dragging windows between sidebar previews, desktops, and workspace cards, with animated drop feedback.
    • Open overview from sidebar preview positions and preserve floating-window placement during drops.

    Overview and navigation

    • Add optional Vim navigation with h/j/k/l and forward/backward selection cycling with Tab/Shift+Tab.
    • Add workspace_strip_force_show and configurable workspace-strip refresh intervals.
    • Restore the pre-overview window on gesture close by default; set gesture_close_restores_focus = 0 for the previous hover-target behavior. Click and Return activate the selected window.
    • Fix cross-workspace gesture exit geometry, confirmed selection focus, and scrolling position after overview teardown.

  3. 0.7.1

    Sep 6, 2026Hyprland 0.56.2v0.7.1-v0.56.2

    Reliable search startup, shutdown, and system appearance

    Search fixes

    • Install hymission-search-input into ~/.local/bin during hyprpm builds and locate it directly at runtime. Fixes #38.
    • Show the search bar immediately when search starts, avoiding an unmapped transparent GTK window that cannot receive its first key.
    • Keep keyboard focus on the search helper and buffer keys while its surface is becoming ready.
    • Prevent desktop freezes when closing search: reset inherited signal state, retire helper processes asynchronously, and force termination after a 250 ms grace period.

    Appearance

    • Follow the system light/dark preference using libadwaita.
    • Render transparent rounded corners without the rectangular window background, with space for the shadow.
    • Correct the plugin-reported version to 0.7.1.

  16. 0.1.1

    Mar 8, 2026Hyprland 0.54.1v0.1.1-v0.54.1

    Gesture handling and configurable empty workspace slots

    Highlights

    • Visible hymission:toggle,* overview can now exit in either swipe direction.
    • recommand only keeps its continuous two-stage transfer in the side-changing direction; the other direction now just exits back to hidden.
    • Hidden-start gestures stay locked to a single opening/cancel session until finger lift, so one touch sequence no longer chains into a fresh visible-start return or cross-side handoff.
    • Added workspace_strip_empty_mode with existing as the default and optional continuous synthetic gap slots.
    • Synthetic empty strip slots now prefer monitor background / wallpaper layers, while the trailing new-workspace slot keeps its dedicated + card styling.
    • Overview rebuilds now retry briefly when a newly relevant window has not reached usable geometry yet.
    • Added a standalone mission layout regression test binary and fixed row-height contamination, candidate-search early exits, negative scale clamps, and aspect-ratio preservation regressions.
    • Synced README, spec, workspace-strip plan notes, and a new dev log for this release.

  17. 0.1.0

    Mar 7, 2026Hyprland 0.54v0.1.0-v0.54

    Workspace strip and two-sided overview gestures

    Highlights

    • Added the first workspace strip implementation for active-workspace overview mode, including strip previews, click-to-switch behavior, and overview-local workspace transitions.
    • Added gesture-only recommand mode for hymission:toggle, so one swipe direction can open forceall while the opposite direction opens onlycurrentworkspace.
